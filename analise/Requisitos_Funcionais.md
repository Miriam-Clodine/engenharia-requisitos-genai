# Requisitos Funcionais

## RF-01 – Consultar eventos disponíveis
O sistema deve permitir que os participantes visualizem todos os eventos disponíveis em um único local.

## RF-02 – Realizar inscrição em eventos
O sistema deve permitir que participantes realizem inscrições em eventos.

## RF-03 – Realizar inscrição em workshops
O sistema deve permitir inscrição em workshops vinculados a um evento.

## RF-04 – Emitir comprovante de inscrição
O sistema deve gerar um comprovante após a inscrição.

## RF-05 – Cancelar inscrição
O sistema deve permitir o cancelamento de inscrições conforme as regras do evento.

## RF-06 – Emitir certificados
O sistema deve permitir a emissão de certificados após o evento.

## RF-07 – Criar eventos
O sistema deve permitir que organizadores criem eventos.

## RF-08 – Gerenciar vagas
O sistema deve controlar automaticamente a quantidade de vagas disponíveis.

## RF-09 – Gerenciar lista de espera
O sistema deve possibilitar a criação e manutenção de lista de espera para eventos lotados.

## RF-10 – Acompanhar inscrições em tempo real
O sistema deve permitir que organizadores acompanhem a quantidade de inscritos.

## RF-11 – Gerenciar participantes
O sistema deve permitir que organizadores consultem e administrem participantes inscritos.

## RF-12 – Gerenciar tipos de eventos
O sistema deve suportar eventos gratuitos e eventos pagos.

## RF-13 – Confirmar pagamentos
O sistema deve permitir a confirmação de pagamentos.

## RF-14 – Liberar inscrições após pagamento
O sistema deve liberar determinadas inscrições somente após a confirmação do pagamento.

## RF-15 – Controlar reembolsos
O sistema deve apoiar o controle de reembolsos.

## RF-16 – Consultar lista de participantes
O sistema deve permitir que palestrantes consultem participantes de suas atividades.

## RF-17 – Consultar programação
O sistema deve permitir que palestrantes consultem a programação das atividades.
